# Lessons

One line per miss: the class of miss and the mechanism that now catches it.

- 2026-09-18 (R13-M3): a client method made a second request for data only one caller shows, adding a failure path for callers that never use it; the lookup moved to the caller that shows the name, pinned by a test that maps an EXACT synonym while the lookup fails.
- 2026-09-18 (R13-M4): only one of two entry points advanced the cancellation generation, so a stale async answer overwrote a newer choice; every entry point now starts a new choice, pinned by a race test and a test that fails when the lookup drops its abort signal.
- 2026-09-18 (R13-M5): a key handler on one part of a composite widget (the combobox input) let the same key from its other part (the listbox) reach document listeners; the handler is on both, pinned by a unit test and the qa `escape` Tab-to-suggestion step.
- 2026-09-18 (R13-M8): a container that fills with long content was itself an aria-live region; the card is labelled instead and a separate one-line status region announces, pinned by a markup test.
- 2026-09-19 (R13-M1): a window-height media query decided how a card split its height between two lists, but the split depended on content the query cannot see (failure notes, wrapping); a grid now shares the height by content with floors, pinned by qa `card-foot-rest`'s share assertion at seven sizes and a unit pin that no height query styles the card.
- 2026-09-19 (R13-M2): a scroll container with no padding clipped its children's focus rings; the rows are inset by the ring's reach, pinned by qa `card-foot-rest` focusing the first and last link and measuring the ring against every clip.
- 2026-09-19 (brief B S-1, fold): a weak fade was the only "more below" cue, and variable-height lines above a primary control pushed it out of a small view; the panel's cue mechanism is shared (moreCue.js) and the control comes first, pinned by qa `card-foot-rest` (cue) and qa `panel-fold`.
- 2026-09-19 (brief B pills): shared label text at 0.3 white was never measured because the contrast check parked the host header; qa `collapsed-pills` now measures every pill's label over the light map and ocean, and qa `contrast` gates the header.
- 2026-09-19 (brief B qa): a qa check's forced-failure state assumed an empty session cache, so an earlier check's cached successes hid the failures and the state never settled, which had been put down to the network; the check now forces failures on keys no cache holds.
- 2026-09-19 (A review I-2): guards after each await were written but only one path was tested, so two of them survived removal; a test per guard (late EXACT match, pick during the map switch) now fails when either is removed.
- 2026-09-19 (A review m-1/m-2): replacing a live region with a one-line announcer dropped what the region used to say (which record, which lookups failed) and repeated identical text; the line names the record and the failures and re-sets identical text, pinned by unit tests and qa `card-announce`, `card-announce-repeat` and `card-foot-rest`.
- 2026-09-19 (A review m-3): the handled-key convention (preventDefault) was honoured by some document Escape handlers and not by the trackers, so one Escape did two things; the five tracker handlers skip handled Escapes, pinned by a vessel wire test and escapeHandled.test.mjs.
- 2026-09-19 (A review m-4): a lookup that only feeds a note was made a hard failure of the whole choice; the taxon now maps by key and the note says the lookup failed.
- 2026-09-19 (B review I-1): a qa check waived its own requirement ("≥1 species row") by a quantity measured from the build under test, so a regression could turn the waiver on; the floors are pinned constants in qa `card-foot-rest` and no size waives the species row.
- 2026-09-19 (B critic S1/S2): two layout fixes moved the loss instead of removing it (landscape kept the secondary parts and dropped the species; the fold moved onto the chosen species); the floors now encode priority and the phone accordion gives the SPECIES body its view, pinned by qa `card-foot-rest` at 667x375 and qa `panel-fold` requiring search, status, chosen row and action whole.
